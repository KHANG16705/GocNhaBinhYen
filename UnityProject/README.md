# UnityProject (Sẵn sàng cho giai đoạn triển khai code)

Thư mục này được chừa sẵn để khởi tạo dự án **Unity 2D** cho *Góc Nhà Bình Yên* (v1.9 — ProjectFinal).

- `.gitignore` ở thư mục gốc đã cấu hình bỏ qua toàn bộ `Library/`, `Temp/`, `Obj/`, `Logs/`, `Builds/`, `UserSettings/`, `.vs/`, `*.csproj`, `*.sln`.
- Khi bắt đầu Mốc 1, tạo dự án Unity 2D tại đây và chỉ copy tài nguyên runtime cần thiết từ `../ProjectFinal/` vào `Assets/_Game/` (bỏ qua `Source/`, `5_Previews/`, `References/`, `Tools/`).
